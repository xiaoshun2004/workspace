# Nova5 纸杯视觉抓取 —— 需求文档（v0）

日期：2026-08-06
状态：待确认

## 1. 目标

以最简单的模式先跑通完整流程：**固定俯拍相机识别纸杯 → 计算抓取点 →
机械臂侧抓 → 放到固定位置**。跑通后再逐步优化（见第 8 节）。

## 2. 硬件与环境

| 项 | 型号/说明 |
|---|---|
| 机械臂 | Dobot Nova 5（6 轴，TCP/IP 模式，IP 192.168.5.1） |
| 夹爪 | 乐白 LMG-90（行程 0–90mm，夹持力 10–35N，RS485/Modbus RTU） |
| 相机 | Intel RealSense D405（理想深度 7–50cm，FOV 87°×58°） |
| 操作系统 | Linux（Ubuntu，当前机器） |
| 目标物体 | 纸杯：杯口 Ø80mm、杯底 Ø60mm、高约 110mm（星巴克 Short 杯） |

参考：`nova5.py`（TCP 驱动）、`gripper_cli.py`（夹爪串口）、`camera.py`（D405 封装）。

## 3. 空间布局（v0 固定方案）

```
            相机 D405（正上方，垂直朝下，离桌面约 25cm）
                 │
    ┌────────────┼────────────┐
    │            ▼            │
    │    取放区 25×18cm       │
    │    （杯子放区内任意处）  │
    └─────────────────────────┘
       机械臂从机器人侧沿 X 水平接近
```

- **相机**：固定在取放区正上方约 25cm，镜头垂直朝下（±10° 内），刚性支架，
  移动后需重新标定。
- **取放区**：相机正下方 25×18cm 矩形区域（D405 在 25cm 高覆盖约 47×28cm）。
- **机械臂基座**：位于取放区一侧，使取放区中心约在机器人前方 250mm
  （X≈250, Y≈0），在臂的舒适工作区内。
- **接近方向**：固定，从机器人侧沿 X 水平接近。
- **放置点**：固定坐标（如 X≈150, Y≈150），一次示教写死；v0 不做视觉放。

## 4. 视觉方案（v0：只出 XY）

- RGB 流 + YOLO（COCO 预训练 `cup` 类）框出杯子 → 框中心 → 单应变换 → 机器人 XY。
- **Z 用固定值**：抓取高度 = 桌面高 + 40mm（杯子高 110mm，抓杯底往上约 40mm，
  该处直径约 72mm）。v0 深度流仅作 RGB 用。
- 若 YOLO 俯视置信度低：备选 HSV/圆形拟合，先不纠结，跑通优先。
- 杯口中心与抓取高度处的锥度偏移（约几 mm），v0 忽略，验收误差预算内。

## 5. 标定（绕开 eye-in-hand）

- 相机固定（eye-to-hand），桌面做**单应变换**：像素 → 机器人 XY。
- 桌面高度 Z 用一个示教点确定。
- 复用旧工程 `calibrate_gui.py` 的思路，标定残差要求 < 3mm。

## 6. 动作序列

1. 视觉给出杯子 XY。
2. 移到预抓取点：XY 不变、沿接近方向退后 80mm，Z = 抓取高 + 30mm。
3. 下降到抓取高度（桌面 + 40mm）。
4. 腕部转 90° 使夹爪水平，夹爪张开到覆盖 72mm 杯身（留余量，实测调）。
5. 沿 X 水平接近杯子，到位后合爪（夹持力调小）。
6. 抬升到安全高度 → 移到放置点上方 → 腕部回正 → 下降 → 张爪 → 抬升。

v0 全部用 `nova5.py` 的 MovL 指令即可，不引入 ROS/MoveIt。

## 7. 验收门槛（按顺序过，过了再走下一步）

1. YOLO 俯视能稳定框住杯子。
2. 单应标定残差 < 3mm；TCP 指到框出的杯子中心，误差 < 5mm。
3. 杯子放固定位置，手动跑完一次完整侧抓
   （调接近速度、爪指长度、夹持力，确认不推倒杯子）。
4. 整链：杯子随机放 5 个位置，连续抓放成功 ≥ 4/5 → v0 跑通。

## 8. 跑通后的优化清单（顺序）

1. 深度测高替代固定 Z（D405 深度 ROI 算杯顶高度）。
2. 杯底椭圆拟合定位（斜视/更精确时用）。
3. 多方向接近（根据杯子周围空间选择）。
4. MoveIt 避障 + 轨迹规划（ROS 2 + 官方 SDK）。
5. 灵巧手 DexHand-021S（替换夹爪，视觉层不变）。

## 9. 已知风险与对策

| 风险 | 对策 |
|---|---|
| 水平接近推倒杯子 | 接近高度偏低、速度慢、夹持力小，真机调参 |
| YOLO 俯视识别不稳 | HSV/圆形拟合兜底 |
| 相机支架晃动导致坐标偏移 | 刚性固定，动过就重新标定 |
| 夹爪爪指包不住 72mm 杯身 | 实测爪指长度，必要时换抓取高度 |
| 锥度中心偏移 | v0 忽略，优化阶段用深度/椭圆拟合补偿 |
