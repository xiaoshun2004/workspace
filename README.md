# 3D 模型库

共 **89** 个模型文件，423 MB。格式分布：3mf × 44、stp × 36、step × 6、scad × 1、stl × 1、ipt × 1。

## 命名规则

```
模型内容_YYYYMMDD.扩展名
```

- **模型内容**：取自原始文件名，清掉副本标记 `(1)`、`+`（网页下载文件名用 + 代替空格）、括号补充说明等冗余，词间用 `_` 连接
- **日期**：优先取文件名里已有的日期（如 `20260609`、`RM-260605`），文件名没有则用文件最后修改日期
- 完整对照表见 `_manifest.csv`

- `.stp/.step` 为 CAD 源文件，`.3mf` 为含模型的切片工程文件，`.stl` 为网格模型，`.scad` 为 OpenSCAD 参数化源码，`.ipt` 为 Inventor 零件。

## 克隆与续传

大文件走 SSH 通道更稳（HTTP 代理会掐断长连接）：

```bash
git clone git@github.com:xiaoshun2004/3D_MODEL.git
```

批量推送可用 `~/.workbuddy/skills/github-large-push/scripts/push_batches.py`：

```bash
python3 ~/.workbuddy/skills/github-large-push/scripts/push_batches.py <仓库目录> 50
```

中断后重跑同一命令即可续传，已上传的部分不会重复传。
