## 命名规则

```
模型内容_YYYYMMDD.扩展名
```

- **模型内容**：取自原始文件名，清掉副本标记 `(1)`、`+`（网页下载文件名用 + 代替空格）、括号补充说明等冗余，词间用 `_` 连接
- **日期**：优先取文件名里已有的日期（如 `20260609`、`RM-260605`），文件名没有则用文件最后修改日期
- 原始文件名与新文件名的对照见 `_manifest.csv`
